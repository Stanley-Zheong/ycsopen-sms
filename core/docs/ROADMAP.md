# Core 实现边界

本文档以 `main` 当前代码和测试为准，不把数据库占位表或页面占位导航当作完成。

## 当前已交付

- Java 21 / Spring Boot 3.3 后端，Flyway 管理 MySQL schema，Redis 支持 nonce、限流和频控。
- 控制台 JWT 会话、平台/租户 RBAC、账号锁定、审计日志、安全事件和敏感数据临时查看。
- 租户注册、资质审核、试用/预付费账本、签名模板生命周期、通道配置与健康状态。
- HTTP 单条短信受理、HMAC-SHA256 验签、幂等、回执、Webhook、批量/定时任务和上游 HTTP/Sandbox 派发。
- CMPP 上下行协议编解码、连接会话、窗口和网关边界；真实运营商账号仍需部署配置。
- 黑名单、内容安全、频控、路由熔断、号码归属/携号转网、投诉处置和多类运营统计。
- 充值、后付费、对账、发票、余额审计、费用预警、异步导出、归档恢复、短链安全等阶段实现。
- PKCS#11 保护字段、盲索引、加密对象、迁移/轮换和泄漏扫描边界。

## 仍需部署方配置或审查

- 生产环境必须替换 JWT、数据库、对象存储和通道凭据，并启用 TLS、密钥设备和监控。
- Sandbox 上游仅用于本地验证；真实 HTTP/CMPP 通道需要运营商参数和联调。
- 默认 `dev` profile 会创建演示管理员和演示数据，不得用于生产。
- 发布前仍应按 PRD 对真实上游回执、资费规则和灾备策略做环境验收。
