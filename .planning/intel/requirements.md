# Synthesized Requirements

- 描述：平台账号管理。

- 范围：F-1 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。

- 范围：F-1 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

### REQ-F-2-8 — 试用管理（注册即试用）

- 描述：试用管理（注册即试用）。
- 验收标准：机构完成注册资料提交后，运营审核通过即自动进入"试用"状态，无需等待正式签约；系统为其配置试用条数额度与试用有效期（起止时间，均可由运营调整）；试用期内按额度扣减发送，额度用尽或到期后自动冻结新增发送（历史数据仍可查询）；机构可在试用期内发起"转正式签约"申请
- 范围：F-2 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

### REQ-F-2-9 — 签约管理（试用转正式）

- 描述：签约管理（试用转正式）。
- 验收标准：运营/财务审核通过转正申请后，登记正式签约信息：计费模式（预付费/后付费二选一）、价格（产品单价/阶梯价，关联具体价目表版本）、后付费授信额度与账期（后付费时必填）、合同编号、签约日期、合同附件；签约生效后机构状态由"试用"变为"已签约"，解除试用额度限制，按正式价格与计费模式计费
- 范围：F-2 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

### REQ-F-2-10 — 停止合作（终止管理）

- 描述：停止合作（终止管理）。
- 验收标准：支持因主动申请、严重违规、长期欠费、资质到期未续等原因终止与机构的合作：运营/财务发起终止申请并注明原因，管理员审批后生效；终止生效后：机构状态置为"已终止"，立即停止受理新的发送提交（含 HTTP/CMPP），吊销/冻结其 API Key 与 CMPP 凭证，下线其签名与模板的可用状态；终止前需完成账务结清（预付费退款或后付费账单结算，见 F-8.6）；终止后历史数据按 10.12 节留存策略继续保留，满足 2 年以上留存与稽核要求
- 范围：F-2 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

## 5. 路由引擎与风控

### REQ-F-5-1 — 黑名单检测（路由前置拦截，硬性要求）

- 描述：黑名单检测（路由前置拦截，硬性要求）。
- 验收标准：路由必须在选择通道之前完成黑名单检测，命中任一黑名单则直接拦截，不产生发送任务，并记录拦截原因；检测源包括：① 系统级黑名单（全平台生效，如已确认骚扰/涉诈号码）；② 机构级黑名单（机构自行维护，仅对该机构生效，如退订用户）；③ 第三方风险名单服务（对接外部黑名单/投诉风险检测 API，如"泰迪短信黑名单"类服务：按号码查询风险分值，分值达到阈值判定为黑名单，支持单号检测与批量检测两种接口，返回拦截来源如"风险拦截/行为预测拦截/用户反馈拦截/靠号拦截/高敏拦截"等分类）。三类检测结果按"任一命中即拦截"合并判定，命中优先级与拦截原因需在详单中可追溯
- 范围：F-5 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

### REQ-F-5-2 — 黑白名单管理

- 描述：黑白名单管理。
- 验收标准：页面同时管理黑名单与白名单，头部统计"黑名单数/白名单数"；列表字段含手机号码、原因、来源（手工添加/批量导入/退订自动加入/第三方风险名单/投诉联动）、状态、创建时间；支持按手机号码/来源/状态筛选查询；支持手工增删、批量导入、导出；白名单优先级高于黑名单（白名单命中则跳过黑名单拦截）
- 范围：F-5 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

### REQ-F-5-3 — 第三方黑名单服务配置

- 描述：第三方黑名单服务配置。
- 验收标准：支持配置对接的第三方风险名单服务地址、鉴权凭证、检测等级（基础/中级/高级）、命中阈值分值、超时降级策略（第三方接口超时/异常时，按配置决定"放行"或"按最近缓存结果判断"，避免因外部依赖故障导致发送链路整体不可用）
- 范围：F-5 模块；页面、字段、状态与数据契约见 PRD 对应小节及第 8、10 章。
- source: docs/PRD.md

### REQ-F-5-4 — 拦截统计与误拦分析
