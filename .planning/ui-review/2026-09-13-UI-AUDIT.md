# UI 审核记录（Chrome）

## 观测范围

使用已打开并启用 Remote Debug 的 Chrome（Chrome 152）登录 `http://127.0.0.1:19089`，通过 Playwright CDP 遍历 admin 路由。

## 证据

- 登录页：登录卡片存在，但复选框约 80px，标签折行，和其它控件比例不一致。
- `/admin/complaints`：登记表单字段分成左右两列且高度很大，动作按钮落在右下角；信息密度、分组和动作对齐不统一。
- `/admin/finance`：查询按钮与字段行虽在同一行，但表头文本连续挤在一起，查询区与表格缺少清晰数据区结构。
- `/admin/review-history`：页面有筛选控件但没有 table；无记录时无法看到列定义。
- `/admin/tools`、`/admin/statistics` 等页面可进入，但需统一查询/数据区和空状态约定。

## Issue 划分

1. 登录页视觉回归：复选框、标签和卡片间距。
2. 全局查询区与控件尺寸：40px 控件、动作对齐、清理孤立筛选框。
3. 投诉列表布局：登记、归因、处理证据和列表分区及动作布局。
4. 财务总览布局：查询动作对齐、表头间距和表格可读性。
5. 审核历史空状态：无记录时仍显示完整表头和跨列空状态。

上述 issue 的统一验收依据为 `docs/frontend页面实现规范.md`，每个 issue 另列页面级 Playwright 验收步骤。
