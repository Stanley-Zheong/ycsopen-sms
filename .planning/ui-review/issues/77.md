## 需求
按 `docs/frontend页面实现规范.md` 统一所有业务页面的查询区、输入框、日期框、下拉框和动作按钮；删除没有实际行为的孤立输入框。

## Playwright 验收标准（Chrome）
1. 遍历 admin 路由，查询区（如有）均可由 `[data-testid="query-panel"]` 定位。
2. 查询区内 input/select/textarea 可视高度为 40px±2px；select 文字与箭头垂直居中。
3. 查询/重置/刷新按钮位于 `[data-testid="query-actions"]`，与字段动作区对齐且不挤入表头。
4. 每个筛选字段有可见 label、稳定 test-id 和对应行为；不存在无用途输入框。
5. 页面无横向滚动。
