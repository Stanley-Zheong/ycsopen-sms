## 需求
优化 `/admin/finance` 查询区和通道财务统计表：查询/查看来源动作对齐，字段与动作间距一致，表头按列分隔并可读。

## Playwright 验收标准（Chrome）
1. 查询字段和按钮位于 `[data-testid="query-panel"]` / `[data-testid="query-actions"]`，按钮高度与输入框一致。
2. 开始日期、结束日期、机构 ID、通道 ID 均可定位且高度为 40px±2px。
3. 两个数据表均使用 `[data-testid="data-table"]`（或语义子 test-id），表头列之间有可读间距，不发生文本粘连。
4. 点击查询后列表区域有明确加载/结果/空状态，页面无横向滚动。
