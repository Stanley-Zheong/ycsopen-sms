## 需求
修复登录页视觉回归，恢复统一登录卡片布局。复选框保持约 16px 可视尺寸，标签单行显示，字段与错误提示间距一致。

## Playwright 验收标准（Chrome）
1. 访问 `/login`，`[data-testid="login-card"]` 可见。
2. `shared-auth-login-remember` 的宽高均在 14–20px；其标签不换行。
3. 用户名、密码、记住用户名、提交按钮均有稳定 test-id，卡片无横向溢出。
4. 输入 `admin` / `Admin@123456` 点击 `admin-console-identity-auth-login-submit` 后进入 `/admin/dashboard`。
