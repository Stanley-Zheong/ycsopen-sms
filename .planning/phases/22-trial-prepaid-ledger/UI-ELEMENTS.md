| Control | Purpose |
| --- | --- |
| `TrialPrepaidLedgerService.consumeTrial(...)` | Covers quota exhaustion/expiry freeze and idempotent message reference handling for `OBL-F-2-8-C`. |
| `TrialPrepaidLedgerService.reservePrepaid(...)` | Covers exact prepaid reserve and insufficient balance rejection for `OBL-F-8-1-A`. |
| `TrialPrepaidLedgerService.confirmPrepaid(...)` and `reversePrepaid(...)` | Covers once-only confirm/reverse semantics for `OBL-F-8-1-B`. |
| `V3100__trial_prepaid_ledger.sql` monetary and ledger columns | Covers exact billing facts for `OBL-DATA-10-8-BILLING`. |
