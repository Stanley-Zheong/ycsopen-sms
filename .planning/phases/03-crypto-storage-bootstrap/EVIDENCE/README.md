A file is not accepted because it exists; it must be produced from the fixed runner's current successful child envelopes and pass the independent evidence validator.

It must not contain raw sensitive fixture values, credentials, capability values, cryptographic key bytes, ciphertext bodies, provider exception text, public object links, production data, local absolute paths or self-authored PASS assertions.

Deterministic adapter results, real MySQL results, real SoftHSM results and real MinIO results remain separately labelled. A missing real boundary keeps its authoritative TODO open.
