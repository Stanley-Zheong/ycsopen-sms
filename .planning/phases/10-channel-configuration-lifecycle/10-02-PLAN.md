## Trust Boundaries

| Boundary | Description |
| --- | --- |
| activation API -> version store | Expected version and configuration payload cross a concurrent mutation boundary. |
| version store -> snapshot registry | Persisted validated data becomes runtime state. |
| activation result -> operator UI/audit | Failure detail must remain safe and non-secret. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-10-02-03 | Repudiation | activation/rejection/rollback | mitigate | Redacted audit includes actor, version, result, and correlation identity. |
| T-10-02-SC | Tampering | package installs | mitigate | No package install is planned. |
