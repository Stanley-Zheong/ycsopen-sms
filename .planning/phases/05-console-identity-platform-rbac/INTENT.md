# Intent

Deliver one production-ready platform-identity vertical slice. A valid platform user can authenticate and administer only what current database permissions allow; disabled, locked, expired, revoked, malformed, or forged access fails closed. Account and role mutations preserve attribution and state history. The desktop Chrome UI exposes the same bounded behavior with stable selectors and controlled Chinese feedback.

The implementation deliberately avoids a generalized IAM product, multi-browser compatibility, tenant identity, password recovery, and a notification engine. Those are not Phase 5 requirements.
