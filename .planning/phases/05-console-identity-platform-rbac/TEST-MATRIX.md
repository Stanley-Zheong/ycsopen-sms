# Phase 5 Test Matrix

The matrix binds every owned obligation to executable evidence. Installed Google Chrome verifies rendered controls, validation, requests, and feedback through `web/playwright.config.ts`; it does not stand in for backend persistence or authorization proof. Java integration, transaction, and security tests verify those server-side effects and are also included in the full Maven suite.
