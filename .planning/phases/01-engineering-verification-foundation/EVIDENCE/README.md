# Phase 1 evidence index

This directory receives machine-readable evidence for exactly seven Phase 1 owned obligations. Evidence is generated by executable commands, contains no credentials or production payloads, and is not PASS until the linked TEST-MATRIX command succeeds. Copy/export and timezone fixtures contribute only to OBL-FOUND-TRACE-003.

## Current local Chrome contract

Two current artifacts have non-interchangeable roles.

`local-chrome-entry.json` is the Plan 00 pre-entry primitive. A standard-library Ruby fixed-argv probe must:

1. Resolve `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` as a regular executable at that exact canonical path.
2. Execute `--version` and require `Google Chrome <full-version>`.
3. Record the full version and derived major at execution time; the current observed version `151.0.7922.174` is not pinned.
4. Launch the same Chrome directly in headless mode with a private temporary profile against a synthetic local page and require an exact marker.
5. Record PASS or stable BLOCKED diagnostics, canonical path, brand, version, fixed command identity, and sanitized launch evidence.

The entry probe has no Playwright dependency, downloads nothing, uses no ChromeDriver, and creates no current/previous version or viewport matrix. A missing path, non-Google brand, or failed launch is BLOCKED/nonzero. An independent reviewer distinct from the Plan 00 executor reruns it, writes the exact four-column current verdict in `ENTRY-REVIEW.md`, and requires the real bootstrap to validate exactly 13 plans with zero exit.

`local-chrome-runtime.json` belongs only to Plan 06. After entry authorization, it records the same installed browser's Playwright launch plus the single `/login` 1440x900 smoke-and-visual execution and supports OBL-NFR-BROWSER. Plan 06 must not create or rewrite `local-chrome-entry.json` or the entry verdict. If the installed Chrome changes, rerun both probes, the smoke/visual scenario, evidence sealing, and affected reviews.
