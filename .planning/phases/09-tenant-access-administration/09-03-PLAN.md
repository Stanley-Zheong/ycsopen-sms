<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| browser -> CMPP credential API | Untrusted tenant credential IDs and network/policy metadata cross into a secret-producing API. |
| service -> protected account/password fields | Sensitive credential values cross into Phase 03 envelope storage. |
| credential administration -> future CMPP session owner | Only status/event metadata crosses; no protocol socket is opened here. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-09-03-01 | Information disclosure | CMPP list/detail response | mitigate | Mask account/password and return only approved connection metadata; no entity serialization. |
| T-09-03-02 | Tampering | endpoint/policy input | mitigate | Validate host/port, allow-list, connection/window/TPS bounds and tenant ownership before transaction. |
| T-09-03-03 | Elevation of privilege | credential revoke | mitigate | Require tenant credential permission and exact tenant predicate; publish only successful state transition. |
| T-09-03-SC | Tampering | package installs | mitigate | No package install is planned for this module. |
</threat_model>
