## Trust Boundaries

| Boundary | Description |
| --- | --- |
| browser -> tenant administrator API | Untrusted user/role IDs and form data cross into authenticated service code. |
| JWT principal -> tenant data | Server identity selects the tenant scope and must not be replaced by request data. |
| service -> users/roles/user_roles | SQL writes and reads cross into shared multi-tenant persistence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-09-01-01 | Elevation of privilege | role assignment | mitigate | Allow only active tenant roles in the actor tenant; reject platform roles and self-escalation. |
| T-09-01-02 | Information disclosure | account list/detail DTO | mitigate | Return explicit safe projections; never serialize password hash, phone envelope, or foreign tenant rows. |
| T-09-01-03 | Tampering | account mutation | mitigate | Derive actor tenant from JWT and execute writes inside transaction with ownership predicates. |
| T-09-01-SC | Tampering | package installs | mitigate | No package install is planned for this module. |
</threat_model>
