## Elements

- `tenant-tenant-console-send-page`: online send page.
- `tenant-tenant-console-send-template`: approved template selector.
- `tenant-tenant-console-send-signature`: readonly approved signature display.
- `tenant-tenant-console-send-recipients`: single or small-batch recipient textarea.
- `tenant-tenant-console-send-variable-code`: variable input example generated from template variables.
- `tenant-tenant-console-send-preview`: canonical preview region.
- `tenant-tenant-console-send-correlation`: current submit correlation identity.
- `tenant-tenant-console-send-submit`: submit button.
- `shared-tenant-console-send-network-error-retry`: network timeout retry button.

Network timeout copy: `网络异常，请检查网络后重试`.
