# Phase 39 Implementation Plan

**Goal:** Build source-backed financial analytics and source drilldown.

**Architecture:** Use one live JDBC query service and one REST controller. Reuse existing admin shell and expose one React workbench through `/admin/finance` and `/admin/statistics`.

**Tech Stack:** Java 21, Spring Boot, JdbcTemplate, Flyway SQL, React, TanStack Query, Vitest, Playwright local Google Chrome.
