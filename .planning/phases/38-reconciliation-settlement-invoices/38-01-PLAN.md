# Phase 38 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use markdown checkboxes for tracking.

**Goal:** Build the minimum source-backed reconciliation, settlement, and invoice loop.

**Architecture:** Use one JDBC service as the phase boundary, one REST controller, and two React pages. Reuse existing trial-prepaid permissions instead of adding a new permission registry.

**Tech Stack:** Java 21, Spring Boot, JdbcTemplate, Flyway SQL, React, TanStack Query, Vitest, Playwright local Google Chrome.

**Spec:** `.planning/phases/38-reconciliation-settlement-invoices/38-SPEC.md`

## Global Constraints

- Do not estimate time.
- Completion means scoped TODO is empty with executable evidence.
- Chrome-only UI verification.
- No mobile implementation.
- Keep the phase focused on statements, differences, settlement, and invoices.
