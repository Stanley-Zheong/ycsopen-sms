# Phase 29 Spec

## Scope

- Tenant bulk import preview and creation.
- Tenant scheduled/bulk task list and controls.
- Admin bulk task detail and send job operations.
- Bulk task/item persistence fields for stable batch/item IDs, item-derived progress, state, priority, cost, and protected phone linkage.

## Boundaries

- Export center is out of scope.
- No downloaded browsers, Edge, Safari, or mobile validation.
- No new compliance/risk/routing logic; valid bulk rows call the existing single-message acceptance service.
