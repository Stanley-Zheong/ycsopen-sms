# skill/

预留给 **jarvis**（此代码库所有者的自动编程/agent 框架）在本仓库内自动编程时使用的技能定义文件。

本次 scaffold 未写入具体 jarvis skill 内容——不了解 jarvis 内部的 skill 文件格式/schema，
写猜测性的占位内容意义不大。建议后续由熟悉 jarvis 的会话／工具补充：

- 本仓库特有的自动化场景，例如："按 core/docs/ROADMAP.md 的下一项 TODO 实现并提交"
  "回归执行 core 的 mvn test 与 web 的 npm test"「补一个新 F-x 功能点的 entity+repo+service+controller+test 五件套」。
- 每个 skill 文件命名与内容结构应与 jarvis 主项目（如 `hengshi-jarvis`）保持一致，本目录不做格式假设。
