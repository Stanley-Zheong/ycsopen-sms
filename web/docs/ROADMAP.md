# Web 实现边界

## 当前已交付

- React 18 + TypeScript + Vite 单应用，统一平台管理端和租户端路由。
- Chrome 目标浏览器下的登录、会话续期、角色守卫、账号/角色、审计、安全事件和敏感查看页面。
- 租户注册/资质、通道配置与健康、签名模板、发送、退订、批量任务、Webhook、频控、黑名单、内容安全。
- 号码归属、供应商状态、路由策略、试用/充值/后付费、对账发票、投诉、告警、报表、异步导出、归档和短链页面。
- 已交付页面使用稳定 `test-id` 合同，并有 Vitest 单测；Chrome Playwright 脚本按阶段目录维护。

## 当前验证

- `npm --prefix web test`：101/101 通过。
- `npm --prefix web run build`：通过。
- 目标浏览器为本机当前安装的 Google Chrome；不承诺 Edge、Safari、Firefox 或移动端兼容性。

## 使用边界

- 页面通过同源 `/api` 调用后端；必须先启动 core 服务并完成数据库迁移。
- 真实上游发送、对象存储和 PKCS#11 功能是否可用取决于后端部署配置。
- 未配置真实依赖时，页面仍可展示本地 Sandbox/演示数据，但不代表生产联调完成。
