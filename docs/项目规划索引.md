# 项目规划与 Phase 过程资料索引

项目的 GSD 规划和每个 Phase 的完整过程资料都保存在当前 Git 仓库中。GSD 约定使用根目录下的
`.planning/`；该目录名称以点开头，因此 macOS Finder 和部分 IDE 默认会隐藏它，但它不是项目外部
目录。

## Phase 过程资料

每个 Phase 位于 `.planning/phases/<阶段编号>-<模块标识>/`。目录中保存该阶段的目标、准入、
计划、执行记录、决策、测试矩阵、审查和证据；不会只存在于对话或本机临时目录中。

## 本机查看隐藏目录

Finder 中按 `Command + Shift + .` 显示隐藏项目，或在项目根目录执行：

```bash
ls -la .planning
ls -la .planning/phases/01-engineering-verification-foundation
```

Phase 资料与对应实现代码一起进入版本控制。阶段只有在 TODO 为空、门禁和审查通过后，才创建并
推送该阶段唯一的原子提交。
